# data-digger-sqlp1
---SQL (Structured Query Language) is the standard programming language used to store, manipulate, and retrieve data stored in a relational database.
---Relational Database Management System (RDBMS): Database engines like MySQL, PostgreSQL, Microsoft SQL Server, and SQLite use SQL to manage structured data stored in tables (rows and columns).

---Primary Key: A unique identifier for each record in a table.

---Foreign Key: A column that creates a link or relationship between two tables.
SQL commands are categorized into four main types:

----1.
DDL (Data Definition Language)

---2.
DML (Data Manipulation Language)

---3.
DQL (Data Query Language)

---4.
DCL (Data Control Language)

---Type of Operator

--1. Arithmetic Operators

Perform mathematical calculations.

--2. Comparison Operators

Compare values and return TRUE/FALSE.

--3. Logical Operators

Combine multiple conditions.

--4. Special Operators

Perform operations like pattern matching and NULL checking.
Data Digger is a useful beginner-level SQL project that provides practical knowledge of database management. It explains how to create tables, insert data, perform CRUD operations, connect tables using primary and foreign keys, and analyze data using aggregate functions.

Through this project, students gain practical SQL knowledge that can be applied in real-world E-Commerce applications.
